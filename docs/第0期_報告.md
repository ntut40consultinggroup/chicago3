## (b1) 投信持股下載

**發現：**
1. 開發沙盒只連得到部分網站：群益、復華、證交所 OpenAPI、櫃買 OpenAPI 可以；**統一（ezmoney）、元大、國泰、富果都連不到**。這是沙盒的網路限制，不代表 Streamlit Cloud 也連不到。Hello app 的「資料來源連線」分頁就是用來從雲端實測。
2. 投信網站多半是單頁應用，持股資料藏在沒有公開文件的內部 API 後面。以群益為例：API 路徑要從前端程式碼反推，網站還有 Incapsula 防爬蟲保護。每家投信都要個別反推，網站一改版就會失效。
3. **統一的付費來源：** 富果開發者 API 有「ETF 持股」端點，提供指定 ETF 每天的成分股、持股數、權重和變動，資料整理自各投信公告。這個端點限開發者、進階方案，歷史資料可回溯到 2019 年。開發者方案月費 NT$1,499、年費 NT$14,990；免費的基本方案不含這類資料。

**D11（請你決定）：持股來源**

| 選項 | 費用 | 可靠度 | 工作量 |
|---|---|---|---|
| A. 各投信自己寫下載程式 | 免費 | 低（改版就壞、可能被擋） | 每家 0.5–1 次對話，之後要維護 |
| B. 富果 ETF 持股 API | 月 1,499 元 | 高（一個介面涵蓋所有 ETF，有歷史） | 0.5 次對話 |
| C. 只做上傳 CSV | 免費 | 高 | 最少；但使用者要自己去投信網站下載 |

**我的建議：** 第一版先做 **C**，保證任何基金都能用；再加 **B** 作為選配（設定裡填富果 token 才啟用）。A 只在雲端連線測試顯示某家特別好抓時才做。

**D11 決定（2026-11-23）：先實測 1–2 家，能抓就加。實測結果兩家都成功：**

| 投信 | 方法 | 歷史 | 驗證 | 程式 |
|---|---|---|---|---|
| 統一（ezmoney） | 基金頁 HTML 內嵌 JSON（`div#DataAsset`），含股票、期貨、現金、淨資產 | **只有最新一天** | 00981A 11/20 的 50 檔，股數與權重和課程手動整理的 CSV **完全一致** | `chicago3/holdings/ezmoney.py` |
| 復華（fhtrust） | 官方 Excel 下載 `/api/assetsExcel/ETFxx/YYYYMMDD` | 可以指定日期（至少回溯到 2026-06）；非交易日回傳空檔 | 00991A 11/20 共 50 檔，股票合計 96.4% | `chicago3/holdings/fhtrust.py` |

- 兩家都能自動抓到旗下 ETF 清單（統一 11 檔、復華 22 檔），下拉選單可以直接用。
- 解析和下載分開寫：解析用存下來的網頁離線測試（5 個測試），下載用 GitHub Actions 在雲端實測，都成功。
- **統一沒有歷史資料：** 第 5 期加一個每天收盤後跑的 GitHub Actions 排程，把持股存到 Drive，慢慢累積歷史。
- **順帶發現：** 00981A 11/20 的淨資產是 2,118 億元，課程用的是 11/13 的 2,752 億元。容量計算吃這個數字，所以網頁版會自動帶入最新淨資產。
- 其他投信（元大、國泰、群益…）和一般共同基金，先用上傳 CSV。需要時再逐家加。

## (b2) OAuth 寫入 Drive

- 個人 Gmail 不能用服務帳戶寫入「我的雲端硬碟」，所以用 OAuth（規劃書 §3.6）。
- **新發現：** 個人 Gmail 的 OAuth 應用程式只能選「外部」。停在「測試中」時，授權和 refresh token 都會在 7 天後失效。對策：
  1. 只用 `drive.file`（非敏感範圍），再把應用程式**發布為「實際運作中」**。
  2. 因此 **D8 微調：** `chicago3.0` 由程式在「我的雲端硬碟」最上層建立。你之後可以把它拖進工作資料夾；程式對自己建立的檔案仍有權限，第 5 期會驗證這點。
- 授權流程完全在雲端完成：app 顯示授權連結 → 你同意 → 把跳轉網址貼回 app → app 顯示 refresh token → 你貼到 Streamlit secrets。token 不經過對話。
- 操作步驟見 `docs/第0期_設定指南.md` 的 A、C 兩節。
