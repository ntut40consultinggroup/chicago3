## 新增模組

| 模組 | 內容 |
|---|---|
| `config` | YAML 設定檔，用 pydantic 驗證。用到不存在的桶、信心不在 0–1 之間、估計期間顛倒，都會直接報錯 |
| `data/twse` | 證交所／櫃買當日快照：股數、產業、收盤、成交值、市值；下載與解析 |
| `data/finmind` | 個股日總報酬（除權息日用參考價、現金股利從市值扣除、非除權息日漲跌逾 10.5% 改用參考價）、報酬指數、日均成交值；下載（402 頻率上限自動等待重試） |
| `buckets` | 分桶規則：單一個股 → 指定個股 → 產業 → 預設；產業重複對應會報錯 |
| `panel` | 個股 → 桶日報酬、桶權重、重建指標；市值以最新值為錨往回推 |
| `capacity` | 每檔取三者最小（淨資產上限、已發行股份上限、出清天數 × 參與率 × 日均成交值），並標出哪一項限制最緊 |
| `pipeline` | 載入 → **勾稽（不過就停下）** → 容量 → 中性 → 均衡與觀點 → 政策 → 區間 → 基金現況 |
| `cli` | `chicago3 reconcile`、`chicago3 policy` 兩個指令 |

設定範例：`examples/00981A_2027.yaml`、`examples/00981A_2025.yaml`。2025 版保留課程「用現在的容量」的做法（講義第 7 節列的後見之明限制），並在設定檔裡註明。
