## 找到並修正：課程原始程式的壓力測試小錯誤

- **問題：** 壓力期間的起日 2026-10-03 是**週六**。原始程式用「刪掉第一列」排除起日，結果桶報酬刪掉的是 10/05（第一個交易日），指標報酬卻沒刪。兩邊量的期間差了一天。
- **影響：** 只影響「相對指標」那一欄。各組合的絕對報酬沒錯（等於從 10/05 高點收盤起算）。
- **修正：** 起日改為 10/05（高點收盤）。相對報酬改成和「用同樣方式重播的指標權重」比，兩邊期間與方法一致。
- **修正後：** 政策組合相對指標 **−1.6**（講義 −1.5）、基金現況 **−13.9**（講義 −13.8）、中性 −1.2（講義 −1.1）。差 0.1 個百分點，結論不變。講義與政策組合書範本的這三個數字之後可以順手更新。

## 新增模組

| 模組 | 內容 |
|---|---|
| `robustness` | 觀點敏感度表、區塊 bootstrap（固定種子，可重現）、情境重播 |
| `attribution` | 月初再平衡回測、每月目標（指標 → 中性 → 加傾斜）、基金市價含息報酬、三層拆解（期間與逐月） |
| `monitor` | 單邊換手、**最近的區間內目標**（在區間內、加總為 1、離現況最近：最省換手的「回到區間」方案）、區間檢查摘要 |
| `report/xlsx` | 19 張工作表，Arial 字型，百分比格式，凍結標題列；「0_說明」頁記錄設定與聲明 |
| `report/policy_book` | 依課程範本九節結構自動填數字；研究依據與失效條件一律標「待補」 |
| `report/charts` | 效率前緣圖、區間圖。配色用 dataviz 參考色盤第 1、2 槽，經 validate_palette.js 驗證（色盲 ΔE 24.7，全部通過）；中文字型自動偵測，找不到就改用英文標籤 |

新發現：**最小換手的回到區間方案只要約 32%**，比直接回到政策目標（39%）少 7 個百分點。這可以當成 SAA 作業 4「選項 B」的成本基礎。

## 設定檔新增

`robustness`（bootstrap、view_grid、stress）與 `attribution`（回溯期間、基金價格與配息檔、要比較的政策）。回溯政策用「在主設定上換掉日期與觀點」的方式定義，不必另外寫一份設定檔。
