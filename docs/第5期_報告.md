## 設計調整：市場資料改成合併檔

規劃書原本是「每檔股票一個檔」，但約 800 個小檔放在 Drive，網頁每次啟動都要下載 800 次，太慢。改成：

```
chicago3.0/
  _market/
    manifest.json        最後更新時間、各資料集抓到哪一天、失敗清單
    prices.parquet       400 檔個股兩年日價（2.1 MB，原本 JSON 約 13 MB）
    dividends.parquet    除權息結果
    tri.parquet          加權報酬指數
    snapshot/20261120/   證交所／櫃買當日快照（4 個檔）
  00981A/holdings/2026-11-20.csv   基金持股
  00981A/holdings/2026-11-20.json  淨資產、來源、現金與其他資產
```

網頁啟動時只要下載約 6 個檔。

## 增量下載怎麼做

- manifest 記錄每檔股票「已經抓到哪一天」。下次只抓那天之後到最新快照日的資料；新進入前 400 大的股票從頭抓。
- 單一股票下載失敗：記在 manifest 的失敗清單，**不標記為已更新**，下次會重試；其他股票照常更新。
- 單一投信網站失敗（例如改版）：記錄錯誤訊息，其他基金照常更新。
- 證交所 API 偶爾斷線（這期實際遇到 connection reset）：自動重試 4 次，間隔逐次拉長。

## 需要你做的事（約 5 分鐘）

1. **設定 GitHub secrets：** 到 repo 的 Settings → Secrets and variables → Actions → New repository secret，新增三個，值從 Streamlit Secrets 的 `[google]` 複製：
   - `GOOGLE_CLIENT_ID`
   - `GOOGLE_CLIENT_SECRET`
   - `GOOGLE_REFRESH_TOKEN`
   - （選填）`FINMIND_TOKEN`：有的話下載比較快
2. **確認 OAuth 應用程式已發布為「實際運作中」：** 如果還在「測試中」，refresh token 7 天就失效，每日排程會在一週後開始失敗。
3. 完成後告訴我，我會手動觸發第一次 `daily-sync`。Drive 是空的，要抓兩年資料，約 20–40 分鐘。
