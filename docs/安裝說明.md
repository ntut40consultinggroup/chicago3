# Chicago 3.0 安裝說明（給業界使用者）

> 這份說明是給**要在自己公司環境執行**的人：持股或觀點屬於機密、不能放上公開網頁的基金經理人和風控人員。只是想試用的話，直接用公開網頁就好（見 `docs/使用手冊.md`）。

## 1. 為什麼要在自己的環境跑

公開網頁跑在 Streamlit Community Cloud 上：網址是公開的，上傳的持股也會經過雲端。在自己的環境跑，**持股、觀點和結果都只留在公司的電腦或伺服器**，不會傳給任何第三方。

程式只會連到公開的市場資料來源，不會上傳任何東西：
- 證交所（openapi.twse.com.tw、www.twse.com.tw）
- 櫃買中心 OpenAPI（www.tpex.org.tw）
- FinMind（api.finmindtrade.com，只在證交所連不上時當備援）
- 統一投信、復華投信的持股頁（只有下載這兩家的基金持股時才會連）

如果公司防火牆要開白名單，開以上網域即可。

## 2. 需求

- Python 3.11 以上（已在 Linux 的 3.12、3.13 測試；macOS、Windows 應該可以，但尚未實測）
- 磁碟：市場資料約 10 MB（400 檔、兩年）
- 網路：第一次下載約 30–40 分鐘，之後每天約 1 分鐘

## 3. 取得程式並安裝

程式放在 GitHub 私人儲存庫 `ntut40consultinggroup/chicago3`。請向 Steve 索取以下其中一種：
- **(a) 儲存庫的讀取權限**（推薦，之後更新只要 `git pull`）
- **(b) 程式壓縮檔** `chicago3-<版本>.zip`

```bash
# (a) 有讀取權限
git clone https://github.com/ntut40consultinggroup/chicago3.git
cd chicago3

# (b) 拿到壓縮檔：解壓後進入資料夾
cd chicago3

# 建立獨立環境並安裝（Windows 啟用環境用 .venv\Scripts\activate）
python -m venv .venv
source .venv/bin/activate
pip install -e ".[app]"        # 含網頁；只用命令列可以改成 pip install -e .

# 確認安裝成功（約 1–2 分鐘；需要原始資料的測試會自動跳過）
pip install -e ".[dev]"
python -m pytest -q tests
```

安裝完成後，會有一個 `chicago3` 指令。

## 4. 下載市場資料

```bash
chicago3 sync --store local:./c3data --funds funds.yaml
```

- `--store local:./c3data`：資料存在這個資料夾。之後每次執行同一行指令，就會只補新的資料。
- `--funds funds.yaml`：要自動下載持股的基金。不需要的基金可以從檔案裡刪掉；如果完全不用自動持股，就把 `--steps` 改成 `snapshot,tri,prices`。
- 其他選項：
  - `--start 2024-11-01`：股價從哪天開始，預設兩年。
  - `--top 400`：股票池大小。
  - `--price-source auto|twse|finmind`：預設 auto，先用證交所，連不上時改用 FinMind。
- 有 FinMind token 的話，可以設環境變數 `FINMIND_TOKEN`，備援時會快一點。

下載完的資料夾結構：

```
c3data/
  _market/
    prices.parquet  dividends.parquet  tri.parquet  manifest.json
    snapshot/20261120/   ← 證交所／櫃買快照，資料夾名稱是日期
  00981A/holdings/2026-11-20.csv   ← 自動下載的持股
```

**每天更新：** 用排程（Linux cron、Windows 工作排程器）在交易日 18:30 以後執行同一行指令即可。

## 5. 準備自己的持股檔

如果不是統一或復華的基金，或者要用公司內部、更即時的持股，就自己準備一個 CSV，UTF-8 編碼：

```csv
type,code,name,weight_pct,shares
stock,2330,台積電,18.22,19303000
stock,2454,聯發科,9.27,5861000
cash,,現金,3.10,
```

- `type`：只有 `stock` 會被計算，其他（cash、futures…）略過。
- `code`：股票代號，用文字格式，不要讓 Excel 吃掉開頭的 0。
- `weight_pct`：占淨資產百分比，例如 18.22 代表 18.22%。程式只看股票部位，會先正規化成 100% 再分桶。
- `name`、`shares` 只是參考，可以留空。

## 6. 寫設定檔

從 `examples/00981A_2027.yaml` 複製一份，至少要改這幾區：

```yaml
fund:
  code: XXXXX
  name: 我的基金
  nav: 5.0e10                     # 淨資產（元），容量計算用

data:
  root: ./c3data                  # 第 4 步的資料夾
  prices_file: _market/prices.parquet
  dividends_file: _market/dividends.parquet
  tri_file: _market/tri.parquet
  snapshot_dir: _market/snapshot/20261120     # 換成最新的日期資料夾
  holdings_file: /secure/path/my_holdings.csv # 第 5 步的持股檔；不填就不比較基金現況
  market: 上市
  universe_top_n: 400

dates:
  asof: 2026-11-20                # 和快照同一天
  estimation: [2025-11-20, 2026-11-20]
  reconcile:
    - [2025-11-20, 2026-11-20]

views:
  - {bucket: AI硬體零組件, excess: 0.05, confidence: 0.50}
```

- 分桶（`buckets`）、限制（`constraints`）、模型（`model`）、TE 預算（`budget`）、區間（`bands`）、穩健性（`robustness`）都可以照範例的預設值，或依基金契約和公司規定調整。每個欄位的意義見 `docs/模型文件.md`。
- 範例最後的 `attribution`（回溯歸因）需要基金自己的價格與配息檔。沒有的話整段刪掉。
- 路徑可以是相對於 `data.root` 的相對路徑，也可以是絕對路徑。

## 7. 執行

```bash
chicago3 reconcile my_fund.yaml               # 只做指標勾稽
chicago3 policy    my_fund.yaml --out out/    # 年度政策組合
chicago3 report    my_fund.yaml --out out/    # 再加上穩健性、監控、報告檔
```

`report` 的輸出：
- `<代號>_<年>_政策組合.xlsx`：所有表格，約 19 張工作表
- `<代號>_<年>_政策組合書.md`：給投資委員會的九節文件
- `<代號>_<年>_效率前緣.png`、`<代號>_<年>_區間.png`
- `<代號>_policy.csv`、`<代號>_summary.json`：給其他系統讀取

勾稽差距超過門檻時，指令會停止並回傳代碼 2。處理方式：檢查資料是否補齊，或調整 `reconcile.tolerance`。

## 8. 在自己的電腦開網頁

```bash
export CHICAGO3_STORE=local:./c3data            # Windows：set CHICAGO3_STORE=local:.\c3data
export CHICAGO3_ADMIN_PASSWORD=自己設一組密碼     # 存結果到資料夾時需要
streamlit run app/streamlit_app.py
```

瀏覽器會開啟 http://localhost:8501 ，操作方式和公開網頁一樣（見使用手冊）。網頁只在你的電腦上跑。持股可以直接上傳 CSV；存檔時會存到 `c3data/<代號>/runs/<時間>/`。

## 9. 更新與問題回報

- 更新：(a) `git pull` 後重新執行 `pip install -e ".[app]"`；(b) 向 Steve 索取新版壓縮檔。版本變更見 `docs/模型文件.md` 第 9 節。
- 常見問題：

| 狀況 | 原因與處理 |
|---|---|
| `sync` 卡在股價很久 | 證交所連不上，正在等重試，之後會改用 FinMind。FinMind 沒有 token 時每小時有次數上限，會自動等待。可以設 `FINMIND_TOKEN`，或先用 `--top 100` 少抓一點 |
| `policy` 出現「各桶上限加總 < 1」 | 淨資產太大、容量不足，或桶上限設太低。調整 `liquidity` 或 `bucket_upper` |
| 「政策最佳化」沒有可行解 | 限制互相衝突，例如單桶最大傾斜太小，或固定的桶太多 |
| 勾稽失敗 | 股價還沒補齊，或估計期間超出已下載的資料 |

- 問題回報：寄給 Steve，附上指令、錯誤訊息和設定檔。**不要附上持股檔。**

使用前請先讀 `docs/免責聲明.md`。
