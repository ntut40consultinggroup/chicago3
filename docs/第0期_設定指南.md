# 第 0 期設定指南：Google OAuth 與 Streamlit 部署

> 這兩件事需要你本人用瀏覽器操作，大約 20 分鐘。程式不會在你的電腦上執行，全部在雲端。

## A. 建立 Google OAuth 用戶端（約 10 分鐘）

1. 用 ntut4.0consultinggroup@gmail.com 登入 https://console.cloud.google.com/ ，建立新專案，名稱填 `chicago3`。
2. 左側選單「API 和服務」→「程式庫」→ 搜尋 **Google Drive API** → 啟用。
3. 「API 和服務」→「OAuth 同意畫面」（新版叫 Google Auth Platform）：
   - 使用者類型：**外部**（個人 Gmail 只能選外部）
   - 應用程式名稱：Chicago 3.0；使用者支援電子郵件、開發人員聯絡資訊：填你的 Gmail
   - 範圍（Data access）：只加 `https://www.googleapis.com/auth/drive.file`
   - 測試使用者：加入你的 Gmail
4. 「憑證」→「建立憑證」→「OAuth 用戶端 ID」→ 應用程式類型選 **電腦版應用程式（Desktop app）** → 建立。記下 **用戶端 ID** 和 **用戶端密鑰**。
5. **重要：發布應用程式。** 回到 OAuth 同意畫面／目標對象（Audience），按「發布應用程式」，改成「實際運作中」。
   - 原因：個人 Gmail 的 app 如果停在「測試中」，授權每 7 天就會失效，要重新授權。
   - 只用 `drive.file` 這個非敏感範圍，發布通常不必送審；如果系統要求先填品牌資料，照畫面補齊即可。發布不了也沒關係，可以先停在測試中，代價是每週重新授權一次。

## B. 部署到 Streamlit Community Cloud（約 10 分鐘）

> 先確認：Community Cloud 每個帳號只能有 1 個私人 app，從私人 repo 部署就占用這個名額。如果 NTUT-AutoML 是從私人 repo 部署的，要先決定讓哪一個改成公開。

1. 到 https://share.streamlit.io/ ，用 GitHub 帳號 ntut40consultinggroup 登入（第一次會要求授權讀取私人 repo，請允許）。
2. 「Create app」→「Deploy a public app from GitHub」：
   - Repository：`ntut40consultinggroup/chicago3`
   - Branch：`main`
   - Main file path：`app/streamlit_app.py`
   - App URL：可以自訂，例如 `chicago3`
3. 展開「Advanced settings」：Python 版本選 3.12；Secrets 貼上：

   ```toml
   [google]
   client_id = "A 步驟 4 的用戶端 ID"
   client_secret = "A 步驟 4 的用戶端密鑰"
   ```

4. 按 Deploy，等 1–3 分鐘。

## C. 在 app 裡完成三項測試

1. **環境**分頁：看到 Python 版本就表示部署成功。
2. **資料來源連線**分頁：按「測試連線」，把結果表截圖給我。這張表決定哪幾家投信可以直接下載持股。
3. **Google Drive**分頁：
   - 點授權連結，用你的 Gmail 同意。
   - 瀏覽器會跳到打不開的 `http://localhost/?code=...`，這是正常的。把整個網址複製，貼回 app。
   - app 會顯示一串 refresh token：複製到 App settings → Secrets，加一行 `refresh_token = "..."`，存檔。這串字等同 Drive 鑰匙，**不要貼到對話裡或分享給別人**。
   - app 重新啟動後，按「建立 chicago3.0 資料夾並寫入測試檔」。成功的話，你的「我的雲端硬碟」最上層會出現 `chicago3.0` 資料夾和一個 hello 測試檔。
4. （可選）把 `chicago3.0` 資料夾拖進專案的 Drive 工作資料夾。app 對自己建立的檔案仍有權限，可以在第 5 期驗證移動後是否照常寫入。
