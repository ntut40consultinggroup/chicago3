# 第 1 期報告：核心計算

> 日期：2026-11-23。

## 結果

七個核心模組完成，全部是純函數：設定值都用參數傳入，不讀檔、不上網、沒有寫死的基金名稱。

| 模組 | 內容 |
|---|---|
| `risk` | 共變異（樣本、Ledoit–Wolf、EWMA）、TE、Beta、波動、相關係數 |
| `equilibrium` | δ、Π = δΣw_B；預期主動 = Beta 溢酬 ＋ 觀點 α |
| `views` | `View`（桶、超額、信心）、Black–Litterman → α = μ_BL − Π |
| `neutral` | 可投資中性（超出上限的部分按比例分配） |
| `optimize` | 政策最佳化（檢查解題狀態，不可行就丟出清楚的錯誤）、解析解、效率前緣、組合指標 |
| `budget` | 策略 TE 上限、戰術空間 |
| `bands` | 再平衡區間、區間狀態 |

**驗證：61 個測試全過**
- **理論性質（24 個，人造資料）：** 沒有觀點時 μ = Π；信心 → 0 時 α → 0；信心 → 1 時觀點組合報酬 → Q；Π'w_B = ERP；Beta 溢酬 = ERP × (β − 1)；沒有 α 時政策等於中性；限制沒綁住時最佳化解等於解析解；中性加總為 1，沒被壓的桶等比例放大；區間包住目標、寬度在 2–10 個百分點之間；不可行時丟出錯誤。
- **重現課程結果（5 個，用第 0 期 fixtures）：** 2027、2025、強烈觀點三組政策的共變異、中性、δ、Π、α 和 TE 預算，與原始程式的差距都小於 10⁻¹²；政策權重的差距小於 10⁻⁶（解題器的數值誤差）；區間、五桶落在區間外的判斷、基金事前 TE 17.28%、β 1.36、2.61% = 2.17% + 0.44%、TE 15% 處前緣組合的 β 1.33，全部重現。
- **測試真的抓得到錯（變異測試）：** 故意拿掉台積電固定，政策權重差 0.77 個百分點，測試失敗；區間下限改成 3%，差 0.16 個百分點，測試失敗。

## 發現：τ 在這個設定下不起作用

觀點不確定性 Ω 設成和 τΣ 成正比（課程與 Idzorek 的做法），τ 會在混合後的預期報酬裡完全消掉。實測 τ 從 0.05 改成 0.5，α 完全不變。

- 代表：**控制觀點強弱的只有「信心」**，τ 不影響政策權重。
- 對網頁的影響：規劃書 §3.5 的參數表原本把 τ 列為可調。改成放在「進階」並註明「不影響結果」，或直接拿掉，以免使用者誤以為調了有用。已加一個測試記錄這個性質。
