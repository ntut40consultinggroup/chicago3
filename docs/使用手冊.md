# Chicago 3.0 使用手冊（網頁版）

> 給學生、Steve，以及想先試用的業界人士。網頁版不用安裝，打開網址就能用。持股屬於機密的話，請在自己的電腦執行（見 `docs/安裝說明.md`）；畫面和操作與本手冊相同。

## 1. 這個工具在做什麼

用一句話說：**根據市場均衡和你的觀點，在追蹤誤差預算之內，算出股票基金各「桶」的年度目標權重和再平衡區間，再和基金現況比較。**

背後的理論在課程「階段 8 補充課：策略性資產配置 SAA」。計算細節見 `docs/模型文件.md`。

## 2. 開始之前

- **左側欄：**
  - **管理密碼：** 只有要把結果存到雲端硬碟時才需要。沒有密碼一樣可以完整分析，也可以下載報告。
  - **資料來源：** 顯示目前讀的是哪個儲存位置。
- **資料不完整時：** 如果系統還在下載市場資料，畫面上方會出現黃色警告，寫出目前有幾檔股價、占股票池市值多少、最後日期是哪天。這時一樣可以從頭跑到尾，但結果**只能當測試**，等資料補齊再正式使用。
- 分頁「系統診斷」是管理用的：檢查資料來源連線、雲端硬碟寫入和同步狀態。

## 3. 七個步驟

### ① 選擇基金

從下拉選單選一檔基金。目前有自動持股來源的：00981A 主動統一台股增長、00403A 主動統一升級50、00991A 主動復華未來50、00418A 主動復華台灣新星。

其他基金選「其他（上傳持股 CSV）」，並填基金淨資產（億元）。CSV 至少要有 `code`（股票代號）和 `weight_pct`（占淨資產百分比，例如 18.22）兩欄。範例：

```csv
code,name,weight_pct
2330,台積電,18.22
2454,聯發科,9.27
```

### ② 收集資料

按「載入資料（已下載的會跳過）」。系統會從雲端硬碟 `chicago3.0/` 取出市場資料和這檔基金最新的持股。如果雲端硬碟的持股比市場資料舊，會先到投信網站下載最新持股：有管理密碼時存進雲端硬碟，沒有就只在這次使用。已經下載過的不會重抓，通常幾秒到幾十秒就完成。完成後，綠色列會顯示持股日期、淨資產和市場資料日期。

完成後可以展開「②′ 勾稽」：用股票池重建的指標，和官方加權報酬指數比較。相關係數接近 1、差距在幾個百分點以內就正常。

### ③ 各桶現況

四個分頁：

| 分頁 | 看什麼 |
|---|---|
| 基金配置 | 基金各桶權重和指標的對照長條圖 |
| 歷史 | 各桶的累積報酬，以及滾動 60 日年化波動 |
| 預期報酬與波動 | 各桶的**均衡預期超額報酬 Π**、波動率、Beta。Π 是「市場是對的」時應得的報酬；歷史平均只供參考，不能當成預期 |
| 相關係數 | 各桶之間的相關係數矩陣 |

### ④ 最佳化

看完現況後，按「Optimize」進入參數設定。

### ⑤ 參數

所有參數都有預設值。不確定就先用預設值跑一次，再一次改一個參數比較差異。

**基本參數**

| 參數 | 預設 | 意義 |
|---|---|---|
| 總 TE 預算 | 0.15 | 基金對指標全年追蹤誤差的上限，分給結構、策略、戰術三層 |
| 資訊比率 IR | 0.50 | 預期每單位主動風險能換到多少主動報酬。越高，模型越敢偏離中性 |
| 股票風險溢酬 ERP | 0.06 | 市場整體對無風險利率的預期超額報酬，決定均衡報酬 Π 的高低 |
| 單桶最大傾斜 | 0.15 | 每桶最多可以偏離可投資中性多少 |
| 出清天數 | 10 | 容量計算：幾天內要能賣完 |
| 每日參與率 | 0.20 | 容量計算：每天最多占該股成交值多少 |
| 單一個股上限 | 0.10 | 法規：單一個股不超過淨資產 10% |
| 台積電上限 | 0.25 | 台積電的個股上限（也是台積電桶的上限） |
| 已發行股份上限 | 0.10 | 法規：不超過該公司已發行股份 10% |
| 基金淨資產 | 自動帶入 | 容量計算用，單位是億元 |

**策略觀點**（可以新增多列）

| 欄位 | 例子 | 意義 |
|---|---|---|
| 桶 | AI 硬體零組件 | 對哪一桶有看法 |
| 年超額 | 0.05 | 你認為這桶未來一年會贏指標多少，0.05 = 5% |
| 信心 | 0.50 | 0–1，越高越相信。真正控制觀點強弱的是信心 |

不填觀點（或年超額填 0）時，政策等於可投資中性：模型不會無中生有偏離。

**進階**（展開才看得到）

| 參數 | 預設 | 意義 |
|---|---|---|
| 共變異估計 | ledoit_wolf | 也可以選 sample（樣本）、ewma（近期權重較高） |
| 估計期間 | 365 天 | 用多長的歷史估計風險 |
| τ | 0.05 | 在這個模型裡不影響結果（見模型文件 5.4 節），保留只是和文獻一致 |
| 區間：TE 增量 | 0.010 | 每桶移動到讓策略 TE 增加這麼多，就是區間邊界 |
| 區間最窄／最寬 | 0.02／0.10 | 區間寬度的上下限 |
| 重抽樣次數、區塊天數 | 300、20 | 穩健性測試 |
| 壓力期間 | 估計期間內的最大回檔 | 也可以改成任何一段歷史期間 |

### ⑥ 執行分析

按「⑥ 執行分析」。完整分析含 300 次重抽樣，通常要幾十秒到一兩分鐘。

### ⑦ 結果

| 區塊 | 怎麼看 |
|---|---|
| 政策目標權重 | 圓餅圖：各桶的年度目標 |
| 政策目標、區間與基金現況 | 每桶的指標 B、中性 N、政策 P、區間上下限、基金現況，以及基金是否在區間外 |
| TE 分層（最上面四個數字） | 結構、策略（和上限）、政策 TE，以及留給戰術＋選股的空間 |
| 基金現況說明 | 幾桶在區間外、基金事前 TE、β、預期主動報酬拆成 **Beta 溢酬 ＋ 觀點 α**，以及回到政策目標或只回到區間邊界的單邊換手 |
| 效率前緣 | 指標、N、P、基金在「主動風險－主動報酬」圖上的位置 |
| 觀點敏感度 | 觀點的年超額和信心改變時，政策怎麼變 |
| 重抽樣 | 各桶權重的 P5、中位數、P95 和區間並列；分布遠超出區間的桶，代表那個權重不穩 |
| 壓力測試 | 指定期間內指標、N、P、基金的報酬與相對報酬 |

**判讀重點：** 一個配置的預期報酬如果大部分是 Beta 溢酬，代表它只是把風險加在高 Beta 的桶上，不是判斷力。

**報告：**
- 「政策組合書（預覽）」：給投資委員會的文件。
- 「下載試算表」「下載政策組合書」：存到自己的電腦。
- 「存到雲端硬碟」：需要管理密碼，存到 `chicago3.0/<代號>/runs/<時間>/`。

## 4. 建議的練習順序

1. 用預設值跑 00981A，記下政策權重、TE 分層，以及基金在區間外的桶。
2. 把觀點的信心從 0.5 改成 0.75，看政策權重和觀點 α 的變化。
3. 把總 TE 預算從 0.15 改成 0.10，看策略空間變多小。
4. 換成 00991A 再跑一次，比較兩檔基金的 β 和 Beta 溢酬。
5. 把基金淨資產加倍，看哪些桶的容量開始卡住。

## 5. 常見問題

| 問題 | 回答 |
|---|---|
| 畫面說市場資料不足 | 系統還沒下載到快照、報酬指數或任何股價。等每天的同步（交易日 18:35）跑完，或請管理者手動觸發 |
| 黃色「資料不完整」警告 | 股價還在補，可以跑，但只能當測試 |
| 分析失敗：各桶上限加總 < 1 | 淨資產太大或流動性參數太嚴，容量不夠放滿 100%。調整出清天數、參與率或淨資產 |
| 分析失敗：政策最佳化沒有可行解 | 限制互相衝突，例如單桶最大傾斜太小。放寬限制再試 |
| 改了 τ 結果都沒變 | 正常，見模型文件 5.4 節 |
| 持股日期不是今天 | 投信通常隔一個交易日才公布持股，畫面會顯示持股日期 |
| 可以用在債券或海外基金嗎 | 不行，只適用以加權報酬指數為指標的台股股票基金 |

使用前請先讀 `docs/免責聲明.md`。
